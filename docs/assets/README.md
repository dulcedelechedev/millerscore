# Controller guide diagrams

These original SVG diagrams explain the controller path to MS Basic, a curve
over time, and CC7/CC11/CC10/CC64. They are illustrations, not screenshots or
measured audio plots. The English and Brazilian Portuguese versions contain the
same numbers, curves and support boundaries.

Each guide embeds its three SVGs inline. The guide therefore remains usable
when copied to a portable package without this asset directory, and makes no
remote requests. These standalone SVG files retain editable vector originals.

| Diagram | English | Brazilian Portuguese |
|---|---|---|
| Sound source and protected lanes | cc-path.en.svg | cc-path.pt-BR.svg |
| Value over time | cc-curve.en.svg | cc-curve.pt-BR.svg |
| Volume, expression, pan and sustain | cc-controls.en.svg | cc-controls.pt-BR.svg |

Every SVG has a title, description and image role. Visible labels, curve points
and controller numbers provide context in addition to color. The guides supply
responsive sizing and text captions. The SVG palette uses an explicit dark
background so its labels remain legible when printed or displayed alongside a
forced-color page.

Generic numbered CC playback is specific to MS Basic/SoundFont and depends on
the selected instrument. The 20 protected numbers are never sent. These diagrams
do not imply generic CC playback in Muse Sounds, VST3 or external MIDI, mixer
automation, or support for every controller meaning.
